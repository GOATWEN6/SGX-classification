## 4. 模型、Guard 与真值问题分类

### 工程/Guard 问题

- `g001` 月份值与年份精度组合没有降级；已修复。
- `g025` 中文两位年份无法支撑四位年份候选；已修复。
- 两个修复均有先失败后通过的回归用例，并提升版本使旧缓存失效。

### 模型语义问题

- `g011` 只有年份矛盾，模型额外标记 event conflict，会增加一次不必要复核。
- `g025` 已声明 time conflict，却没有输出图片中的另一条 `2001` 时间候选，冲突解释不完整。

### Truth/评分口径问题

- `g007` 原文只说“小聚”，把 `聚会` 判错、强制要求 `家庭聚会` 缺少关系证据；时间角色按现行 `.12` Prompt 应为 `event`，模型输出的 `capture` 是角色偏差。
- `g007` 要求 `庆典` 而排斥清晰可见的 `桌面`，依据不足。
- `g023` 的 `自然景观` 有明确画面依据，作为额外场景不应自动等同严重错误。

这些项目应先由独立 truth 审核修订“可接受别名、时间角色和多标签策略”，再冻结 validation Gate。不能用同一批模型输出直接修改 validation truth。
