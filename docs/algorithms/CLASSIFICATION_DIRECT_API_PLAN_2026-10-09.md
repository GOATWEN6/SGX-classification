# 2026-10-09 独立算法 API 执行计划

## 已确认目标

算法侧在云端 `127.0.0.1:8765` 提供完整任务 API；模型组件移至仅本机的
`127.0.0.1:8766`。全栈负责 HTTPS 映射、产品鉴权、原始文件存储和页面接入。
外部接入不再要求 Worker pull、租约、心跳或反向 SSH 控制面。

复用已验证的分类核心、Prompt、OCR、embedding、授权后人脸候选、ASR、历史候选
和预算账本。人物姓名、亲属关系、敏感事实和长期 Memory 仍须产品独立确认。

## 执行顺序及完成条件

1. **接口与实现**：提交图文/final ASR 返回 `jobId/sessionId`；状态与结果查询；录音
   ASR 任务；每个读写请求校验家庭、主体和操作人；幂等重发不重复付费。
2. **持久与运行**：使用 SGX 独立持久数据目录；中断任务保留可见失败而不自动重试；
   内部执行器和组件服务由独立程序管理，保留旧 release/日志。定位空闲退出并明确
   平台实例常驻与进程恢复的区别，未经时间验证不宣称 SLA。
3. **必要验证**：新增 HTTP 边界聚焦测试；真实 ASR；新增入口的一条真实图文任务，
   然后重启读取同结果。付费前核对累计 200 次/¥50 授权、账本与到期时间，0 自动重试；
   无有效授权时保留付费阻塞并继续无费用工作。不重复已有完整算法矩阵。
4. **交付**：提供中文说明、精确路由/字段/限制、curl 示例、运行与恢复命令、证据和
   已知边界；提交到现有 GitHub 交付分支。公网验收由全栈完成 HTTPS 映射后执行。

## 验收边界

服务代码测试、真实模型链路、部署持续性、公网可达和产品质量分别报告。
本轮不重选模型、不改相关性策略、不增加依赖、不修改平台全局 preload 或其他项目。
